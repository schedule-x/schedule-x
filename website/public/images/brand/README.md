# Schedule-X brand assets

The light and dark wordmarks in this directory are the canonical website and
repository exports. Their final X uses four identical mirrored diagonal arms.
Each arm has a short, flat inward face, and the four faces form a centered
diamond-shaped negative space.

The wordmark's outer silhouette, proportions, colors, and typography must stay
unchanged when producing additional exports. The eight-tile favicon is a
separate mark and is not derived from the wordmark's final X.
